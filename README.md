# Supplier Management API — Spring Boot

Backend service for searching and managing supplier information.

## Overview
This Spring Boot application exposes supplier-related functionality. The API implementation defines the supported search criteria, request payloads, and supplier data returned to clients.

## Related Project
- [Supplier Management React Frontend](https://github.com/MahiTzy/supplier-management-ui-react)

## Technology
- Java
- Spring Boot
- REST APIs
- Database and dependencies declared by the project build

## Getting Started
1. Install the JDK and build tool required by the project.
2. Clone the repository:
   ```bash
   git clone https://github.com/MahiTzy/makersharks-supplier-api-springboot.git
   cd makersharks-supplier-api-springboot
   ```
3. Review application configuration and configure the required datasource or external services.
4. Run with the Maven wrapper if present (`./mvnw spring-boot:run`) or use the configured build tool.

## API Reference
Inspect controller mappings and request/response models for the actual supplier search filters, endpoint paths, and response format. Do not assume routes that are not present in the code.

## Configuration & Security
Externalize credentials and environment-specific values. Do not commit production secrets or private connection strings.
